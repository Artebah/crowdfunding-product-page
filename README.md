# Crowdfunding Product Page
Crowdfunding Product Page is a web application designed to manage and display crowdfunding campaigns using TypeScript, SCSS, HTML, and CSS.

## Technologies
* TypeScript
* SCSS
* HTML
* CSS

## Features
**Responsive Design:**
Ensures optimal viewing experience across various devices.

**Interactive UI Components:**
Includes interactive elements built with TypeScript.

**Styling with SCSS and CSS:**
Uses SCSS for modular and maintainable styles along with CSS.

## How to launch:
You can view the live version of the project [here](https://crowdfunding-product-page-eta.vercel.app/).
